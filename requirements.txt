# ComfyUI-H3-Latent-Relay 运行时依赖
#
# 只列「本包直接 import 的第三方库」。
# ComfyUI 本身（comfy.* / folder_paths / node_helpers）由宿主提供，不在此列。
#
# 依赖说明：
#   · torch 是**模块顶层 import**（relay_core.py）——缺少它 = 整包注册失败，
#     ComfyUI 里看不到任何 H3 Relay 节点（宿主 ComfyUI 必带 torch，正常安装无需操心）。
#   · safetensors 只在落盘/读回时**函数内延迟 import**（relay_core.save_av_latent /
#     load_av_latent）——缺少它时节点仍能注册，用到落盘那一步才报错。
#   · av / numpy 只在「多段拼接成片」（Chain 的 🧩 / auto_concat）里**延迟 import**——
#     不用拼接功能的人**完全不受影响**；宿主 ComfyUI 本来就自带（其 requirements 里有 av>=17）。
#     缺它们时只有点拼接那一下会报「装法」明确的错，不会影响节点注册与跑链。
#   · packaging / comfy-aimdo **都不是本包直接 import 的**，而是 V3 出口的传递依赖：
#     V3 走 `comfy_api.latest`，它的链上会拉
#       `comfy_api.internal.api_registry` → `from packaging import version`
#       `comfy.memory_management` / `comfy.storage` → `import comfy_aimdo`
#     实测（2026-09-24 GitHub Actions）宿主缺任一个，V3 出口就 ModuleNotFoundError。
#     本包已加「V3 加载失败 ⇒ 回退 V1 + 警告」的兜底，所以缺它们不会让整包挂，
#     但**默认出口就会静默变成 V1** —— 想用 V3 就必须有它们，故在此显式声明。
#     （`comfy-aimdo` 零依赖、纯 Python 命名空间包，装它无负担。）

safetensors>=0.4
torch>=2.0
av>=17
numpy
packaging
