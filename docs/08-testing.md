## 单测（零 GPU、秒级）

```bash
python tests/test_relay_core.py
```

脚本会自动上溯定位 ComfyUI 根目录；装在别处时用
`COMFYUI_PATH=/path/to/ComfyUI python tests/test_relay_core.py`。也支持 `pytest tests/`。

⚠️ **`pytest tests/` 与逐脚本跑**（2026-10-07 实测）：三条跑法现在**结果一致**。此前不一致 —— `pytest` 把三个脚本式测试跑在**同一个进程**里，而 `test_relay_core` / `test_experimental` 会把**本包目录**插进 `sys.path`（它们要离线加载 `nodes.py`）⇒ 之后 `test_v3_schema` 的 `import nodes` 会绑到**我们自己那份**（影子模块）⇒ 一度落到 **63/0 · 7 节点**。**根因已修**（`nodes.py::_comfy_registry` 不再让 ImportError 穿透 —— 见「V3 逐字段一致」一节），影子模块**不再影响节点是否在场**，所以现在 `pytest tests/` 直接给出 `72/0 · 8 节点`。

**断言主体按组分片**在 `tests/cases/`（7 个 `_g*.py`）。`tests/test_relay_core.py` 只留文件头 /
定位 / `check()` / **分片执行** / 汇总。分片用 `exec(compile(src, path, "exec"), globals())`
**顺序执行到同一个命名空间** —— 与拆分前的单文件扁平脚本**同一 globals、同一顺序**，所以
跨组共享的夹具变量照旧可见。⚠️ 分片文件名以 `_` 开头 ⇒ `pytest tests/` **不会**单独收集它们
（否则每条断言会跑两遍）。

  `class_type.参数名` 分节点建表，只留核心句 + 推荐值）** · 词表形状自检（空项 / zh==en / 八个节点齐全）。
  🔴 **词表完整性不在这一层**（那是 Python 的活）：`review_050.py` 的 H3n/H3p 项直接拿
  `nodes.py` 的 `INPUT_TYPES` 键核对两张表 ⇒ **新增参数忘了翻译（标签或提示）在机检那一层红**。
  提示写进 `widget.tooltip`（前端优先读它、且序列化**从不写**它那一格）⇒ 分享出去的图不带翻译、
  别人的图也不受影响；
- 静态扫描：阶段表 ↔ `say()` 相位串、**会提交的按钮是否都过了 `run_id` 闸**；
- **断言数自引用**：`ci.yml` 与本文档里写的「期望 N/0」必须等于实跑数 ——
  同一个数字写在三处就一定会漂（本仓 2026-10-02 亲历：一份门槛表漂了 7 天没人发现）。
  ⚠️ **0.6.23 起判据是「三边相等」**：声明值 == 文件里的常量 == **本文件此刻实跑的通过数**。
  只比「声明 == 常量」会漏掉**改了断言却忘改常量**那种假绿 —— 实测加固后当场抓到一个（加了断言没改常量）。

### 英文文档同步闸（`tools/en_sync.py`，2026-09-30 新增）

**为什么不是"自动翻译"**：机翻会把实测数字（`0.0007`）与标识符（`settle_frames`）静默改掉，
而本仓机检**只扫中文源** ⇒ 英文版会变成监管盲区。所以闸只做三件事：**盯同步 / 自动重写机械面 /
生成翻译任务书**。

| 命令 | 作用 |
|---|---|
| `python tools/en_sync.py` | 闸（= `--check`）：**0** 同步 / **1** 有节未同步 / **2** 闸失效 |
| `--status` | 逐节报告（新鲜 / 源已改 / 未登记 / 暂缓 / 有意不译） |
| `--brief <节>` | 生成增量翻译任务书（该节中文原文 + 术语表 + 硬约束），交译者或 LLM |
| `--apply` | **只**重写机械面：版本号 / 文件头 `<!-- EN-SYNC -->` 标记 / 索引表缺行（不碰散文） |
| `--stamp` | 翻译完成后登记（源 hash + 英文 hash） |
| `--omit "节" --why …` | 登记「有意不译」（`--stamp` 时**新增节默认 todo ⇒ 红**，逼人做决定） |
| `--ack "节" --why … --until 日期` | 登记暂缓（**带期限**；到期自动重新变红） |

状态文件 `tools/en_sync.json`（节映射 + 双端 hash + ack 台账）、术语表 `tools/en_glossary.json`。
**加一对文档 = 在 `en_sync.py` 的 `PAIRS` 里加一行**。打包前也会跑这道闸（英文过期就不出包）。

规则（三条，改闸前先读）：① **单一源**（英文里不许出现中文源没有的断言数字）；
② **默认必须译**（未登记的源节 = 红）；③ **fail-closed**（清单缺/坏 ⇒ 退出码 2，绝不返回 0）。
