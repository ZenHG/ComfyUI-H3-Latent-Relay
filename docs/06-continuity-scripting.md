## 🎬 接缝处的对话规避与音频处理（出词纪律 + 音频缝配套）

### 0. 长台词要跨缝怎么办（2026-09-21 定稿）

**先说能力边界**：音频是每段**独立生成**的 —— 节点能保证「不吞字 + 音色一致（refs）+ 时间轴对齐」，
**保证不了跨缝的韵律衔接**（语速/语调是两次采样的巧合）。所以跨段长台词的答案按优先级：

| 方案 | 做法 | 连续性 | 代价 |
|---|---|---|---|
| **① 句子不断 ⇒ 别跨缝（首选）** | 把缝放在句子**之后**：该段单独加长（如 `length=288` = 12s 说完整句），缝落在句尾气口 | ★★★ 段内同一生成，韵律天然连续 | 段长加大 = 单段成本↑ |
| **② 必须跨缝 ⇒ 断点放气口** | seg1 说前半（句尾落在段尾安全区），seg2 头部留白后说后半；断点选**标点/换气**，别选词中间 | ★★ 靠出词侧设计；音色由 refs 保一致 | 韵律衔接靠运气，需耳检 |
| **③ 台词整句落进缝区（❌ 不做）** | 句子横跨缝且缝在词中间 | ✗ 必出伪音/吞字 | — |

**② 的预算表**（台词安全窗，按 `trim=22` 帧 + 🛡 守卫开启计）：

| 段长 | 裁头 | 头部留白（守卫余量） | 尾部缓冲 | **台词安全窗** | 约合字数 |
|---|---|---|---|---|---|
| 4s（96 帧） | 0.92s | ≥1.2s | ≥0.5s | **≈1.4s** | 4–6 字 |
| 8s（192 帧） | 0.92s | ≥1.2s | ≥0.5s | **≈5.4s** | 16–20 字 |
| 12s（288 帧） | 0.92s | ≥1.2s | ≥0.5s | **≈9.4s** | 28–34 字 |

**开关清单（跨段台词场景逐项过）**：

| 开关 | 该处于 | 为什么 |
|---|---|---|
| 🛡 `patch_guard` | **开（默认）** | 自动避让本段头部台词 —— 它就是为这个场景生的（0.6.5） |
| `patch_seconds` | 可留 2.0（有守卫兜底）；绝对保守 ⇒ 0 | 守卫会自动收缩/关闭，不再吞字 |
| `settle_frames` | **0**（默认） | 自动沉降最多多裁 36 帧 ≈1.5s ⇒ 直接吃台词 |
| 组装层 `--across` | **0**（0.6.2 起默认） | crossfade 每缝偷 0.25s ⇒ 台词错位+吞字 |
| `trim_frames` | **22 不许动** | 桥的时序网格硬要求（5+17k），关掉=续接不成立 |
| ~~E1/E2/E5~~ | **已移除**（2026-09-22） | 🔴 三层实验档实测**对靶无效**，已在 `1c87aff` 一并删除 ⇒ 现在**没有**这几个参数。⚠ E1 的后续想法仍在（GG 2026-09-25），恢复入口见 `CHANGES.md` 该提交条目 |

**判收**：缝前后 ±1.2s 耳检 —— 词要完整、气口要自然；ASR 词级时间戳可当尺子
（`faster_whisper word_timestamps=True`），但**终判是人耳**。

### 🎬 接缝处的对话规避与音频处理（出词纪律 + 音频缝配套）

节点链把**画面**接缝处理干净（钉住 → 裁头 → 沉降），但接缝区还有两类坑
在**出词侧**和**音频侧**，三者是一套配合，缺一角就出伪音/断句：

### 1. 段首缓冲：续接段开头要留出「裁头 + 余量」

裁重叠会吃掉续接段头部 = **`trim_frames`（钉住区，默认 22 帧）+ `settle_frames`（沉降：0.5.0 起默认 `0` 不裁；开自动 `-1` 时按检测路上限分别是 12 帧（硬跳/色档路）/ 36 帧（锐度塌陷路））**。
**0.5.0 默认只裁 22**；最坏情形（自动沉降取满 36 帧）≈ **58 帧 ≈ 2.42s**（实测典型值：cond 桥 ≈ 38 帧 ≈ 1.58s）。对话排在这里会被**拦腰裁掉**（实测教训：台词起音被裁）。

⇒ 续接段开头 **≥ 裁头 + 0.2s 不排台词**（0.5.0 默认只裁钉住区 ⇒ ≥1.1s；若开了自动沉降 ⇒ ≥2.6s）；续接段的 `[Shot 1]` 只写画面与机位承接，
台词从后面的 Shot 起。**保守起见直接按第 2 条的 ≥3.6s 排，两条约束同时满足。**

> ⚠️ **`settle_frames` 裁的是「新内容」，不是重复内容——这是最容易踩的一条。**
> 裁切量 = `trim_frames + settle_frames`，但两笔账性质完全不同：
> - `trim_frames` = 上一段尾的**复现**（重复画面，上一段已经放过）→ **裁它不丢东西**；
> - `settle_frames` = **本段新生成的内容** → **裁它就会丢**。
>
> 所以**段首有台词 / 关键动作 / 不可丢内容的场景**，二选一：
> 1. 用**拷贝桥 `mask_mode="hard"`**（钉住区逐位拷贝、模型不重画 → **不产生复现发糊**
>    → **根本不需要沉降裁切**，内容零风险）；或
> 2. 把 **`settle_frames` 设为 `0`**（只裁钉住区，最安全），代价是段首可能留一点糊。
>
> 拿不准就先设 `0` 跑一段，看桥/裁节点的 `report` 里报的塌陷深度再决定要不要开自动。

### 2. 台词安全时刻公式

```text
续接段台词的 prompt 时刻 ≥ 实际沉降裁头 + 音频缝补丁 N(建议 2.0s) + 0.2s 余量
0.5.0 默认（settle=0）⇒ ≥2.2s；开自动沉降（−1，典型 ≈24 帧）⇒ ≥3.2s
实际建议一律排 3.6s —— 两种情形同时满足
```

由来：🔗 续接音频缝补的 room tone 头部补丁（见第 4 条）只保留本段音频 N 秒之后的部分，
prompt 时刻换算到段内时刻后必须落在保留区。出词校验若有「首切点 ≤3s」
之类的节奏规则，把**切点与台词解耦**：切点排 2.8s，台词挂在 3.6s 的 Shot 上。

### 3. 末帧锚链：段 N 的末帧状态在段 N+1 出词里逐字复写

接力点选在**镜头运动中途 / 动作未完成**处；段 N+1 的 `<Video 1>`（或等价的
末帧参照）逐字复写段 N 末帧：谁在什么位置、手停在哪里、镜头推到哪。
跨段"一镜到底"的观感是**出词纪律**撑起来的，节点只保证不重播不跳切。

### 4. 音频接缝：**节点**把上一段的环境声补进本段头

H3 每段独立生成音频，续接段头部有两件事叠在一起：

- **解码 priming**：段首约 32ms 近静默（实测 −72 dB）——裁重叠把它正好放到裁切点上
  ⇒ 成片缝处**先"抽一下"再起乐**（缝起 20ms 比缝前低 12–13 dB，听感即"静音一瞬"）；
- **生成重启瞬态**：0~1.4s（实测频谱 0-1s 中高频达环境声 10×、20-60Hz 达 6×，
  低频尾巴衰减到 ~1.4s 才回环境水平）。

🔗 **续接音频缝**用一条等长的替换治掉这两件：把本段头部 `patch_seconds` 秒换成
**上一段的最静窗环境声**（stationary 噪声，拼接不可闻），到第 N 秒处交叉淡变回本段
自身音频，**之后一个采样点都不动**。

| 参数 | 做什么 | 什么时候用 |
|---|---|---|
| `patch_seconds`（默认 0） | 后段头部 N 秒整段替换为**前段最静窗**（自动选窗避开台词尾） | 建议 2.0（盖过 1.4s 瞬态尾巴） |
| `tile_seconds`（默认 0） | 床源改取 W 秒瓦片**自叠化环铺**满 N | 前段干净环境窗比 N 短时（台词密），用 1.2 |
| `fade_seconds`（默认 0.25） | 补丁边界的交叉淡变宽度 | 0 = 硬切（有可闻接点） |

**为什么必须在节点里做，而不是组装层**（这是 0.5.0 的路线修正）：

1. **效果要落进段文件**。组装层的补丁是"渲染之后的第二步"——UI 里播放、逐段验收、
   交付中间产物看到的都还是没有补丁的音频；节点版从段文件出来就带环境声。
2. **组装层 crossfade 有 A/V 位移**。ffmpeg `acrossfade` 的语义是**裁掉后段的头部 X 秒**
   （交叉区消耗的是后段内容）⇒ 每条缝让缝之后的**音频相对画面提前 X 秒**。
   实测（2 段、X=0.25）：音乐峰从 8.75s 移到 8.50s，而总时长不变（尾部补平）——
   4 段链就是累计 0.75s 的 A/V 相对位移。**节点的 patch 是等长替换，零位移。**

> ⚠️ 真 crossfade（两段叠化）**做不到"单段内长度守恒"**：它要裁掉**上一段**的尾巴，
> 而单段节点只能改本段。所以 crossfade 仍归组装层（需要时），等长路线用本节点。

频带剖面判据（同算法在组装层做的 A/B 实测，口径一致）：补丁前缝区 60-250Hz 达环境声
**4×**（可闻"无理由伪音"）；补丁后 ≈**1.0×**（与全片环境声中位持平）。
宽带口径：**补丁后缝邻域最静点不再落在缝上**（旧配方 Δ = −26.4 dB → 补丁后 Δ = −1.1 dB）。

**段首纪律仍是前提**：补丁会把这 N 秒换成环境声，所以续接段**前 1.2s 不该有台词**
（见上一条「段首缓冲」公式）。

### 5. 长片：段数没有机制上限

stage 链（落盘/读回）按段号自续（本段段号 - 1 = 要读的段号），节点上限 9999 段；
每段 192 帧（8s）即可任意延长成片。**漂移累积**——色档/角色/锐度随接力次数衰减
（2 段实测缝亮度阶跃 0.0004，目检"几乎完美"；≥3 段未系统实测）——0.5.0 起有**外观锚**治理：
复合桥（0.6.0 唯一桥）填 `ref_anchor_stage=0`（或接 `ref_anchor_latent`）即可让每段以第 1 段为身份基准，
锚不随接力退出（见「参数」两张表）。≥3 段仍建议逐缝机检：

- 视频缝亮度阶跃 ≤0.008（0-1 口径；>0.03 即硬切级——无缝口径专用，
  分镜剧的正常切镜本来就在这一档）；
- 音频缝区 60-250Hz ≤ 全片环境声中位 1.5×（>2.5 为 FAIL，瞬态凸起案实测 2.7~4×）；
- 组装四断言：帧数守恒 / PTS 无洞 / DTS 递增 / A·VΔ。
